## 🎢 1. Roller Coaster Ticketing System

A Python-based command-line ticketing system that simulates the ticket-purchasing workflow of a roller coaster attraction.

The program validates a visitor's eligibility based on height, determines the ticket price according to predefined age categories, and optionally adds the cost of a photo package. The final ticket cost is calculated dynamically based on the user's selections.

### Technical Highlights

* Height-based eligibility validation
* Age-based pricing logic
* Optional service/add-on handling
* Dynamic price calculation
* Interactive command-line input

### Concepts Demonstrated

`if/elif/else` • comparison operators • user input • variables • conditional logic

# ☔ 14. Rain Alert System

An API-driven Python automation project designed to monitor upcoming weather conditions and notify the user when rain is expected.

The application retrieves forecast data from the **OpenWeatherMap API**, analyzes the upcoming **12 hours of forecast intervals**, and searches for rain-related conditions such as rain, drizzle, showers, and thunderstorms.

When qualifying weather conditions are detected, the system automatically generates and sends an email alert through an SMTP server.

### Technical Highlights

* REST API integration
* 12-hour forecast analysis
* Weather-condition filtering
* Rainfall data processing
* Automated email notifications
* Date/time processing
* Conditional alert generation

### Technologies

**Python • Requests • OpenWeatherMap API • SMTP • EmailMessage • datetime**

### System Workflow

```text
OpenWeatherMap API
        ↓
Forecast Retrieval
        ↓
12-Hour Forecast Analysis
        ↓
Weather Condition Detection
        ↓
 ┌───────────────┐
 │ Rain Detected?│
 └───────┬───────┘
       YES │
           ↓
      Email Alert
```
